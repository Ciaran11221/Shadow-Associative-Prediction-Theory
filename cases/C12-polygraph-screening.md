# C12. The polygraph fails at screening

**What happened.** The polygraph reads bodily arousal as a shadow of lying. The US National Academies concluded that it is too inaccurate to screen employees for security risks: when real cases are rare, screening throws up many false positives for each true one, and it can create a false sense of security.

**What it shows.** The shadow has another cause, fear, so it fails REAL ([S13](../shadows/S13-arousal-for-lying.md)); L1 only counts shadows that pass. And screening everything makes most flags false, which is why the method is judged by how few things it shows a person (R8).
