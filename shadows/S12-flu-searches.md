# S12. Web searches for flu (failed)

| Field | Value |
|---|---|
| Hidden quantity | Flu cases |
| Shadow | Google searches about flu |
| What happened | In February 2013 it estimated about double the official level ([C09](../cases/C09-google-flu-trends.md)) |
| Why it failed | Search habits and Google's own search changes moved the shadow, and it wasn't kept in check against official counts |
