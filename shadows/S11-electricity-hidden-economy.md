# S11. Electricity use for the hidden economy

| Field | Value |
|---|---|
| Hidden quantity | Economic activity missing from official figures (the shadow economy) |
| Shadow | Electricity consumption |
| Why it moves | Most activity uses power; if power use grows faster than reported GDP, the gap suggests hidden activity |
| Other causes | Technology and efficiency change how much power each unit of output needs |
| Calibrated on | An assumed one-to-one link between power use and output, which critics say drifts as technology changes |
| Speed | Months to years |
| Record | Kaufmann & Kaliberda's method, 1996 |
