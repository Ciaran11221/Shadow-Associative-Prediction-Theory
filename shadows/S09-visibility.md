# S09. How far you can see, for haze

| Field | Value |
|---|---|
| Hidden quantity | Particle pollution (haze), including before monitors existed |
| Shadow | Visibility: how far observers can see, logged at weather stations |
| Why it moves | Particles scatter light |
| Other causes | Humidity, fog, rain |
| Calibrated on | Measured particle levels where both exist |
| Speed | Daily |
| Record | Decades of weather-station logs |

**Known result.** Clear-sky visibility fell over land from 1973 to 2007 (Wang et al., Science, 2009).

## Sources

- [Wang et al. 2009, Science](https://doi.org/10.1126/science.1167549)
