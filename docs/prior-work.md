# Prior work

Parts of this already exist. This page names them, so the theory can be judged on what's actually new.

| Work | What it does | How it relates |
|---|---|---|
| Data assimilation in weather forecasting | Combines millions of observations with a physics model several times a day, weighting each by how far it can be trusted | The most successful working version of "many angles, one picture" (L2) |
| Project Cybersyn, Chile, 1971–73 | A real-time control room for a national economy | The "all the data in one room" idea; ended by the 1973 coup |
| GEOSS, Group on Earth Observations, since 2005 | 100+ governments linking Earth-observation data | Cross-field data joining at government scale |
| Destination Earth, EU | A digital copy of the planet; full version due by 2030 | The largest current attempt at one model of the physical world |
| Climate TRACE | Emissions estimates for large sources worldwide, from satellites and other independent data | Independent angles on official emissions, using shadows such as steam plumes ([S05](../shadows/S05-cooling-tower-steam.md)) |
| Guan et al., 2012 | Found a 1.4 billion tonne CO2 gap between China's national and provincial statistics for 2010 | L3 by accounting, three years before the official revision ([C05](../cases/C05-china-coal-2015.md)) |
| Martinez, 2022 | Night-time light against dictators' GDP figures | L3 with a known answer; the basis of test T1 ([C06](../cases/C06-dictator-gdp-night-lights.md)) |
| Kaufmann & Kaliberda, 1996 | Electricity use as a shadow of hidden economic activity | A shadow method from economics ([S11](../shadows/S11-electricity-hidden-economy.md)) |
| Miao, Tchetgen Tchetgen and others | Shadow variables for data that's missing because of its value | The statistics behind the name |
| UNEP Methane Alert and Response System, since 2022 | Satellite methane alerts sent to governments and companies | Detection at scale; replies rose from 1% to 12% in a year ([C08](../cases/C08-unep-methane-alerts.md), R9) |
| Hayek, 1945 | The knowledge that matters is scattered and mostly unwritten | The strongest objection to the premise ([THEORY.md](../THEORY.md), section 8) |

## What's different here

1. **One catalogue of shadows across fields**, scored on one test. Today each recipe sits in its own field's journals.
2. **Laws that state how they could fail**, with tests planned before any results.
3. **Rules learned from cases**, each traceable to the event that taught it.

Whether these differences matter is what the tests are for.
