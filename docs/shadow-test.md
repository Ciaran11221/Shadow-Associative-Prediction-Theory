# The shadow test

A shadow is a measurable stand-in for a hidden quantity. Before any shadow is used, it's scored on three questions.

```text
REAL     it moves when the hidden quantity moves      lichens thin as SO2 rises
         and its other causes are known                birds also die from habitat loss, cats, pesticides
PROVEN   it was matched to direct readings             the 1970 lichen scale was set against measured SO2
         and still holds on data it wasn't found in    see the 1,000-variable trap below
USEFUL   its speed fits the job                        minutes -> alerts (canaries)
                                                       years   -> history (lichens, leaves)
```

## Scores used in shadows/

| Field | Allowed values |
|---|---|
| real | yes, partly, no |
| proven | yes, partly, failed, not-yet |
| useful | alerts, history, both, no |

## The 1,000-variable trap

A computer hunting for shadows across many variables will find some by luck. Test 1,000 unrelated variables at the usual 5% threshold and about 50 will "match": 1,000 × 5% = 50. The defence is PROVEN's second line: a shadow only counts if it still holds on data it wasn't found in.

## The calibration trap (R3)

A shadow has to be calibrated: you learn how much it moves for each unit of the hidden quantity. Calibrate it on the source you're checking and it inherits that source's lie, because a lie that's been steady from day one looks like a perfect pattern. Calibrate on independent, trusted sources instead. The dictator-GDP study ([C06](../cases/C06-dictator-gdp-night-lights.md)) used countries with trusted figures as the reference, then checked autocracies against it.

## Checking a source is not checking a value (R1)

```text
source check:  WHO said it, WHEN      -> spoofed or not
cross-check:   IS IT TRUE             -> independent angles agree or not

both pass          -> trusted
source only        -> "official, unconfirmed"
cross-check only   -> "confirmed, source unknown"
neither            -> parked, never deleted (R4)
```
